# Hussein Badr English — HH

منصة تعليمية عربية لتعلّم اللغة الإنجليزية من الصفر إلى المستويات المتقدمة.

## النشر على GitHub Pages

- المستودع: `gnathussinbder-star/HH`
- رابط الموقع: https://gnathussinbder-star.github.io/HH/
- ارفع **محتويات هذه الحزمة** إلى جذر المستودع، بحيث يكون `index.html` في المستوى الأول مباشرة.
- من إعدادات المستودع افتح **Settings → Pages**، واختر **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)`.
- لا يتطلب الموقع خادمًا خلفيًا أو خطوة بناء. إنه موقع ثابت HTML/CSS/JavaScript.

## ملاحظات

- تأكد من وجود مجلدات `assets/css` و`assets/js` و`assets/img` كما هي داخل الحزمة.
- بيانات التقدم والاختبارات تحفظ محليًا في متصفح الزائر، ولا تُرسل إلى خادم.
- تم تحديث مسارات النشر لتطابق اسم المستودع `HH`.
- هذه الحزمة لا تتضمن ملفات PDF.


## الهوية البصرية المعتمدة

تم تحديث الصورة الشخصية والشعار من الملفات التي زوّد بها صاحب الموقع.
لوحة الألوان الرسمية:
- Navy: `#102B4C`
- Yellow: `#FFD447`
- White: `#FFFFFF`
- Support blue: `#7598BD`
- Pale gray: `#F5F7FA`

ملفات الشعار بأحجام متعددة محفوظة داخل `assets/img/`، والصورة الشخصية في `assets/img/hbe-portrait.jpg`.
